Sync From MSSQL
Sync Data from MSSQL to Odoo

Installation
- pip install pyodbc
- Install this addon

--note: if you run in linux ,you must install Microsoft ODBC 17 first,please refer to this page:https://learn.microsoft.com/zh-tw/sql/connect/odbc/linux-mac/installing-the-microsoft-odbc-driver-for-sql-server?view=sql-server-2017&tabs=ubuntu18-install%2Cubuntu17-install%2Cdebian8-install%2Credhat7-13-install%2Crhel7-offline#17

Configuration
--From Odoo, go to Settings -> Database structure -> Sync From MSSQL
