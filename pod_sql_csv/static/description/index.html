SQL to CSV

SQL to CSV lets you query your database with SELECT SQL query and get a CSV back with the results !

Compatible with Odoo SH and On Premise versions


Configuration steps (screenshots below to help)

    In Odoo:
  • 1/ Install the module
  • 2/ That's it ! You can head to Settings -> Technical (debug mode should be activated) -> SQL to CSV, enter your SQL, and click "Generate CSV"
