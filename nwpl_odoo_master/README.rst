=================
nwpl_odoo_master
=================

This repository contains the master branch of the nwpl_odoo project, 
which is a collection of Odoo modules designed to enhance the functionality 
of Odoo for a custom orthotics manufacturing environement.

The modules are designed to work together, providing a comprehensive solution
for managing products, sales, manufacturing, and accounting processes.

The modules include:
- **pod_access_control**: Access control for the orthotics manufacturing environment.
- **pod_contacts**: Contact management for customers and suppliers.
- **pod_customer_statement**: Customer statement management.
- **cpq**: Core functionality for custom product configuration.
- **cpq_sale**: Integration with sales processes.
- **cpq_sale_mrp**: Integration with sales and manufacturing processes.
- **cpq_mrp**: Integration with manufacturing processes.
- **cpq_mrp_account**: Integration with manufacturing and accounting processes.
- **cpq_account**: Integration with accounting processes.
